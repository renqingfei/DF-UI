## 一、表单增强

### 1. DatePicker 日期选择器

整个组件库最复杂的组件之一，日期计算逻辑全部放在 `@df-ui/core`。

| 属性 | 说明 |
| --- | --- |
| `modelValue` | 支持 Date / 时间戳 / 字符串，由 `valueFormat` 决定 |
| `type` | `date` `daterange` `datetime` `datetimerange` `month` `year` `week` `time` `timerange` |
| `format` / `valueFormat` | 显示格式与绑定值格式分离 |
| `disabledDate` | 函数，返回 true 的日期不可选 |
| `shortcuts` | 快捷选项（今天 / 最近 7 天 / 本月…） |
| `minDate` / `maxDate` | 可选范围 |
| `clearable` `readonly` `placeholder` | — |

| 端 | 表现 |
| --- | --- |
| pc | 弹出日历面板，可键盘导航，范围选择双面板联动 |
| h5 / uni | 底部弹出：日历式（月视图）或滚轮式（年月日列）二选一，由 `mode` 控制 |

**自研而非依赖 dayjs 全量**：core 中实现所需的日期计算（加减、边界、周计算、格式化），避免为一个组件引入整个日期库。

---

### 2. Upload 文件上传

| 属性 | 说明 |
| --- | --- |
| `modelValue` | 文件列表 |
| `action` / `customRequest` | 上传地址，或完全自定义上传逻辑 |
| `accept` `multiple` `limit` `maxSize` | 类型、多选、数量与体积限制 |
| `listType` | `text` `picture` `picture-card` |
| `beforeUpload` | 返回 false 或 Promise 拦截，可做压缩/裁剪 |
| `autoUpload` `drag`（PC） | 自动上传、拖拽上传 |

事件：`change` `success` `error` `progress` `exceed` `remove` `preview`

**平台差异**：这是三端实现差异最大的组件。
- pc / h5 用 `FileReader` + `XMLHttpRequest`（需要进度事件）
- uni 端走 `uni.chooseImage` / `uni.chooseFile` / `uni.uploadFile`，小程序端不支持任意文件类型，需在文档中明确各小程序平台能力矩阵

---

### 3. Cascader 级联选择

`options`（树形数据）· `props`（字段映射）· `multiple` · `checkStrictly`（父子不关联）· `showAllLevels` · `lazy` + `lazyLoad`（动态加载子节点）· `filterable`

pc：多列面板并排展开 · h5 / uni：底部弹层内 Tabs 逐级选择

---

### 4. InputNumber 数字输入框

`min` `max` `step` `stepStrictly` `precision` `controls` `controlsPosition`（右侧上下 / 两侧加减）
内部用整数运算规避浮点误差（`0.1 + 0.2` 问题）。

---

### 5. Slider 滑块

`min` `max` `step` `range`（双滑块）`vertical` `marks`（刻度标记）`showTooltip` `formatTooltip` `disabled`
移动端需处理触摸事件与滚动冲突；uni 端尺寸测量走 `createSelectorQuery` 异步接口。

### 6. Rate 评分

`count` `allowHalf` `allowClear` `colors`（分段颜色）`texts`（分段文案）`icon` `readonly`

### 7. Search 搜索框

`modelValue` `placeholder` `shape`（square/round）`background` `showAction`（右侧取消按钮）`clearable`
事件：`search`（回车或点搜索）`cancel` `clear`
移动端聚焦时自动展开取消按钮，配合 `NavBar` 使用。

## 二、数据展示

### 8. Tree 树形控件（仅 PC）

`data` `props` `nodeKey` `showCheckbox` `checkStrictly` `defaultExpandAll` `expandOnClickNode` `accordion` `draggable` `lazy` + `load` `filterNodeMethod`
方法：`getCheckedKeys` `setCheckedKeys` `getCurrentNode` `filter`
数据量大时内部启用虚拟滚动。

> 移动端不做 Tree，改用 Cascader 或分页面逐级下钻，符合小屏交互习惯。

---

### 9. Collapse 折叠面板

`modelValue`（展开项）`accordion`（手风琴，同时只开一个）`border`
`CollapseItem`：`name` `title` `disabled`，插槽 `title` `default` `extra`

---

### 10. Progress 进度条

`percentage` `type`（line/circle/dashboard）`strokeWidth` `status`（success/warning/error）`showText` `textInside` `color`（支持函数或分段数组）`indeterminate`（未知进度的循环动画）

**平台差异**：uni 端 `circle` 类型用 CSS `conic-gradient` 实现（小程序 canvas 成本高、层级易出问题）。

---

### 11. Image 图片

`src` `fit` `lazy`（懒加载）`preview`（点击全屏预览，支持手势缩放）`previewList` `radius` `width` `height`
`placeholder` / `error` 插槽：加载中与失败时的占位。

**平台差异**：uni 端懒加载直接用 `image` 组件的 `lazy-load` 属性；预览走 `uni.previewImage` 原生能力。

---

### 12. Swiper 轮播图

`modelValue` `autoplay` `interval` `duration` `loop` `vertical` `indicator`（dots/fraction/none）`indicatorPosition` `touchable` `lazyRender`
事件：`change` `click`

**平台差异**：uni 端直接封装小程序原生 `swiper`（性能远优于自绘）；pc / h5 用 CSS transform + 触摸/鼠标拖拽自实现。

---

### 13. VirtualList 虚拟长列表

上万条数据只渲染可视区域的那十几条。

`data` `itemHeight`（固定或函数）`buffer` `keyField` `horizontal`
支持不定高（动态测量 + 位置缓存）。

**平台差异**：uni 端无法同步测量元素高度，不定高模式改为"预估高度 + 渲染后异步修正"，并提供 `recycle-view` 兜底方案。

## 三、反馈与交互

### 14. Drawer 抽屉

从边缘滑出的大面板，与 Dialog 共用底层弹层逻辑。
`modelValue` `direction`（rtl/ltr/ttb/btt）`size` `title` `showClose` `modal` `closeOnClickModal` `beforeClose`

---

### 15. Dropdown 下拉菜单

`trigger`（hover/click/contextmenu）`placement` `disabled` `hideOnClick` `splitButton`
`DropdownItem`：`command` `disabled` `divided` `icon`

移动端 `trigger` 强制为 click，面板从触发点或底部展开。

---

### 16. Tooltip / Popover 气泡（仅 PC）

`content` `placement`（12 个方位）`trigger` `effect`（dark/light）`offset` `showArrow` `disabled` `showAfter` `hideAfter`
定位引擎放在 core 层，Dropdown / Select / DatePicker 共用同一套边界检测与自动翻转逻辑。

> 移动端无 hover，且屏幕窄放不下气泡，改用 Toast 或 ActionSheet 表达同类信息。

---

### 17. ActionSheet 动作面板（H5 / uni）

从底部弹出的操作列表。
`modelValue` `actions`（`[{ name, subname, color, disabled, loading }]`）`title` `description` `cancelText` `closeOnClickAction` `safeAreaInsetBottom`
支持函数式调用：`DfActionSheet({ actions }).then(selected => …)`

---

### 18. SwipeCell 滑动单元格（H5 / uni）

列表项左滑露出"删除/置顶"按钮。
`leftWidth` `rightWidth` `disabled` `beforeClose`（点击按钮后异步确认再关闭）
插槽：`left` `right` `default`

**平台差异**：uni 端用 `touchmove` + `transform` 实现，需处理与页面纵向滚动的手势冲突（方向锁定）。

---

### 19. PullRefresh 下拉刷新 + InfiniteScroll 上拉加载（H5 / uni）

| 组件 | 属性 |
| --- | --- |
| `PullRefresh` | `modelValue`（刷新中）`pullingText` `loosingText` `loadingText` `successText` `headHeight` `disabled` |
| `InfiniteScroll` | `loading` `finished` `error` `offset` `immediateCheck` `finishedText` `errorText` |

两者组合即"下拉刷新 + 触底加载更多"的完整列表页。
**平台差异**：uni 端优先接管页面级 `onReachBottom` 与 `onPullDownRefresh` 生命周期，性能优于组件内滚动监听。

## 四、导航

### 20. Steps 步骤条

`active` `direction`（horizontal/vertical）`alignCenter` `simple` `finishStatus` `processStatus` `clickable`
