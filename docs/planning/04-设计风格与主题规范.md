## 一、四种候选风格

四种风格**不是四套代码**，而是同一套组件在不同令牌值下的表现。定稿后只保留一套作为默认，其余作为可选预设保留。

| 参数 | A 规整专业 | **B 现代圆润** | C 轻快移动 | D 极简线性 |
| --- | --- | --- | --- | --- |
| 参照 | Element Plus、阿里后台 | Ant Design 5、飞书 | 微信/支付宝小程序 | Notion、Linear |
| 圆角（小/中/大） | 2 / 4 / 4 px | 4 / 6 / 10 px | 8 / 12 / 20 px | 3 / 4 / 6 px |
| 边框 | 1px 明显灰线 | 1px 柔和灰线 | 几乎不用，靠背景色区分 | 1px 极淡细线，全局统一 |
| 阴影 | 几乎不用 | 柔和多层阴影 | 大范围弥散阴影 | 完全不用 |
| 控件高度（中） | 32 px | 36 px | 44 px | 34 px |
| 字号基准 | 14 px | 14 px | 15 px | 14 px |
| 标题字重 | 500 | 600 | 600 | 500 |
| 间距密度 | 紧凑（8 基数） | 舒适（8 基数，多一档） | 宽松（12 基数） | 紧凑（8 基数） |
| 主色使用 | 按钮、链接、选中态 | 按钮、链接、选中态、强调背景 | 大面积色块、渐变 | **克制**，仅关键操作 |
| 适合 | 信息密集的后台管理 | 后台与 App 通吃 | 手机端、面向消费者 | 工具类、内容类产品 |

### 风格差异的实现方式

```
风格 = 一组令牌覆盖值
├─ --df-radius-sm / -md / -lg
├─ --df-border-width / --df-border-color
├─ --df-shadow-sm / -md / -lg
├─ --df-control-height-sm / -md / -lg
├─ --df-font-size-base / --df-font-weight-title
└─ --df-spacing-unit
```

切换风格 = 换一份令牌 JSON，组件代码零改动。

## 三、色阶推导

由一个主色推出 10 级色阶，浅色主题与暗色主题各一套。

```
--df-primary-1   最浅，用于选中背景、hover 底色
--df-primary-2   浅背景
--df-primary-3   边框（浅）
--df-primary-4   边框
--df-primary-5   hover 态描边
--df-primary-6   ★ 主色本体（按钮底色、链接色）
--df-primary-7   hover 加深
--df-primary-8   active 按下
--df-primary-9   深文字
--df-primary-10  最深
```

**推导规则**（HSL 空间，向白/黑各插值 5 级，并对色相与饱和度做感知补偿）：

- 浅色方向：降低饱和度、提高亮度，色相向暖侧微移，避免变灰变脏
- 深色方向：提高饱和度、降低亮度，色相向冷侧微移，避免发浑
- 暗色主题下整体降低饱和度约 15%，并把主色本体从第 6 级换到第 5 级，防止在深色背景上刺眼

## 六、尺寸阶梯

### 字号

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--df-font-size-xs` | 12 px | 辅助说明、角标 |
| `--df-font-size-sm` | 13 px | 次要文字 |
| `--df-font-size-base` | 14 px | 正文 |
| `--df-font-size-lg` | 16 px | 小标题 |
| `--df-font-size-xl` | 18 px | 标题 |
| `--df-font-size-2xl` | 20 px | 大标题 |
| `--df-font-size-3xl` | 24 px | 页面主标题 |

移动端整体上浮 1px（`base` 为 15px），保证小屏可读。

### 间距

以 4 为最小单位：`2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`
令牌：`--df-space-2xs` ~ `--df-space-3xl`

### 圆角

`--df-radius-xs / sm / md / lg / xl / full`，具体值由风格决定（见第一节）

### 阴影

| --- | --- |

| `--df-shadow-lg` | 弹窗、抽屉 |

## 七、动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--df-duration-fast` | 120 ms | 颜色/透明度变化 |
| `--df-duration-base` | 200 ms | 常规过渡 |
| `--df-duration-slow` | 320 ms | 弹层进出 |
| `--df-ease-out` | `cubic-bezier(.25,.8,.5,1)` | 进入 |
| `--df-ease-in` | `cubic-bezier(.4,0,1,1)` | 退出 |
| `--df-ease-in-out` | `cubic-bezier(.4,0,.2,1)` | 位移 |

**无障碍**：检测 `prefers-reduced-motion: reduce` 时，所有动画时长归零，仅保留状态变化。

## 八、层级（z-index）

统一由 `@df-ui/core` 的弹层管理器分配，禁止组件内写死。

| 层 | 基准值 |
| --- | --- |
| 吸顶/固钉 | 100 |
| 下拉面板 / 气泡 | 1000 |
| 遮罩 | 2000 |
| 弹窗 / 抽屉 / 弹出层 | 2001 起递增 |
| 消息条 / 轻提示 | 5000 |
| 全屏加载 | 9000 |

同类弹层多次打开时依次 +2（遮罩与内容各占一层）。

## 九、令牌命名规范

```
--df-{类别}-{语义}-{层级/状态}

--df-color-primary            语义色
--df-primary-6                色阶
--df-text-secondary           文字
--df-bg-container             背景
--df-border-base              边框
--df-radius-md                圆角
--df-space-lg                 间距
--df-shadow-sm                阴影

--df-button-primary-bg        组件级令牌（可单独覆盖，不影响其他组件）
--df-input-height-md
```

规则：

1. 全部小写，短横线分隔，统一 `--df-` 前缀
2. 组件级令牌必须默认指向语义令牌，不得写死色值
3. 新增令牌需同步更新 `packages/tokens` 的类型定义与文档

## 十、暗色主题

实现方式：`<html data-theme="dark">` 切换根节点属性，覆盖第二层语义令牌，组件代码零改动。

要求：

- 所有组件必须在两种主题下都验收
- 暗色下不使用纯黑 `#000` 与纯白 `#fff`，避免眩光
- 阴影在暗色下减弱、改用边框强化层次
- 图片与图标需检查在深色背景下的可辨识度
