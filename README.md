# DF UI

一套面向 Vue 3 的三端组件库：**PC 后台**、**手机 H5**、**uniapp（小程序 / App）**。

三端共享同一套设计令牌、同一套逻辑内核、同一套组件 API，各自保留最贴合平台习惯的界面表现。

---

## 这是什么

| | 说明 |
| --- | --- |
| 定位 | 自研 UI 组件库，对标 Element Plus（PC）+ Vant（H5）+ uview（uniapp），三者合一 |
| 技术栈 | Vue 3 + TypeScript + Vite + pnpm workspace（monorepo） |
| 发布形态 | `@df-ui/pc`、`@df-ui/h5`、`@df-ui/uni` 三个 npm 包 |
| 文档站 | VitePress，三端文档在同一站点，可在线预览与复制代码 |
| 当前阶段 | **规划中**，尚未开始编码 |

---

## 仓库结构（规划）

```
DF_UI/
├─ packages/
│  ├─ core/          纯逻辑：表单校验、弹层管理、日期计算、状态钩子（0 界面代码，三端共用）
│  ├─ tokens/        设计令牌：颜色 / 圆角 / 间距 / 字号 / 阴影（改一处，三端同时变）
│  ├─ icons/         图标（自动产出网页版 SVG 与小程序版两种产物）
│  ├─ pc/            @df-ui/pc    PC 后台版
│  ├─ h5/            @df-ui/h5    手机网页版
│  └─ uni/           @df-ui/uni   uniapp 版（微信小程序 / App / 多端）
├─ docs/
│  ├─ planning/      规划文档（架构方案、组件清单、主题规范）
│  └─ session/       开发会话记录
├─ preview/          静态预览页（不依赖构建，浏览器直接打开）
├─ playground/       三个实时预览工程，边写边看效果
└─ scripts/          构建、发版、生成新组件模板的脚本
```

## 视觉风格

**默认风格：Liquid Glass（液态玻璃）**，对标 iOS 26 设计语言。

两个预览页都是纯静态 HTML，**双击即可在浏览器打开**，无需安装任何东西：

| 文件 | 内容 |
| --- | --- |
| `preview/ios26-liquid-glass.html` | **主方案**。玻璃组件、PC 后台整页、三个手机页面；顶部可实时调模糊/通透度/高光/圆角、换壁纸与主色 |
| `preview/style-preview.html` | 备选。四种传统扁平风格（Element / 飞书 / 小程序 / Notion 风）并排对比 |
